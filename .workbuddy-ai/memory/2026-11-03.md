## 根因（一锤定音）
**不是 Cloudflare 拦人，是站点换了服务器，而新 IP 从本机网络被静默丢包。**

| IP | 使用区间（OTX passive DNS） |

## 证据链
1. **Chrome 错误页**：探针截图显示 `ERR_CONNECTION_TIMED_OUT`，`location.protocol='chrome-error:'`。
   → Chrome 错误页标题就是主机名，所以看起来像 `title='wxredian.com' links=0`，
   **被误读成"Turnstile 没过"，白等 150s × 6 轮**（10-30 上午 4 次 + 10-30 10:03 两次 + 本日一次）。
2. **TCP 层**：新 IP 443/80/8080/8443 全部 timeout；`ping` 100% 丢包、**无 RST** → 防火墙静默 DROP。
3. **对照实验**：腾讯云香港节点 43.154.175.195 返回 **ConnectionRefused（RST）** → 到香港的路由本身是通的，
   说明只针对这一个 IP。同机 github.com / baidu.com 均 0.0~0.1s 连通 → 不是断网。
4. **DNS**：DoH（dns.google）权威解析同为 207.57.135.129（TTL 60），老 IP 已下线。
5. **站点是活的**：换出口（WebFetch）首页正常，热文流最新 **2026-10-31 23:59**。
6. **挑战只针对内容路径**：`/author`、`/art` → 跳 `/verify?redirect=`；`/`、`/index?page=N`、`/sitemap.xml`(404) 不拦。
   → 非浏览器客户端拿不到正文；但真实 Chrome + 可达网络是可以过的（10-26 就是这么过的）。
